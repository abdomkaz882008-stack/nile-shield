# 🛡️ NILE SHIELD - درع النيل
### From NASA Data to Every Egyptian Farmer

> نظام إنذار مبكر لحماية النيل من التلوث والفيضان

**Challenge:** NASA Space Apps Cairo 2026 | **Owner:** abdomkaz882008-stack | **Location:** Sohag, Egypt - Sahil Tahta

### 🏗️ هندسة النظام - 3 طبقات

**1. طبقة الفضاء (Space Layer):**
- Landsat 8/9 بيصور النيل كل يوم
- GPM بيقيس المطر على منابع النيل
- SRTM خريطة ارتفاعات الأرض

**2. طبقة الذكاء (AI Layer):**
- كود Python يحلل لون النيل: أخضر=نظيف، بني=ملوث
- نموذج AI يتوقع الفيضان قبلها بـ 72 ساعة

**3. طبقة الأرض (Ground Layer):**
- داش بورد Streamlit للمسؤولين
- رسائل SMS للفلاحين في سوهاج
- خريطة تفاعلية لمكان التلوث

### 🛰️ بيانات ناسا المستخدمة
